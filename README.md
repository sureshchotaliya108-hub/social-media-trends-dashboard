# Social Media Trends Dashboard

## Overview
This project analyzes social media engagement across regions, platforms, and content types using Power BI.

## Tools Used
- Power BI
- Excel / CSV dataset

## Key Insights
- USA shows highest share activity
- Video content drives maximum engagement
- Festive campaigns increase reach significantly
